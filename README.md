# DocuFlow — Сервис автоматического заполнения документов Word и Excel

Веб-сервис для пакетного и автоматического заполнения документов **Word** (`.docx`, `.doc`) и **Excel** (`.xlsx`, `.xlsm`, `.xls`) по тегам `{tag}`, с личными аккаунтами пользователей, архивом готовых комплектов документов, генератором ссылок для шеринга и защищенным изолированным хранилищем.

Исходный код и релизы проекта доступны на GitHub:  
👉 **[https://github.com/Koob-ise/DocuFlow](https://github.com/Koob-ise/DocuFlow)**

---

## ⚡ Быстрая установка и скачивание

Вы можете скачать проект напрямую с GitHub:

```bash
# 1. Клонирование репозитория в рабочую директорию /opt/docuflow
mkdir -p /opt /srv/files/DocuFlow
cd /opt
git clone https://github.com/Koob-ise/DocuFlow.git docuflow
cd /opt/docuflow

# Либо скачивание ZIP-архива напрямую:
# wget https://github.com/Koob-ise/DocuFlow/archive/refs/heads/main.zip
# unzip main.zip && mv DocuFlow-main docuflow
```

## 🚀 Развертывание в Docker

Все шаблоны, профили пользователей и архивы хранятся в постоянной директории `/srv/files/DocuFlow`.

### Вариант 1. Запуск через Docker Compose (Рекомендуется)

```bash
cd /opt/docuflow

# Запуск в фоновом режиме со сборкой
docker compose up -d --build
```

### Вариант 2. Запуск через Docker CLI

```bash
cd /opt/docuflow

# Сборка образа
docker build -t docuflow:latest .

# Запуск контейнера с монтированием каталога шаблонов
docker run -d \
  --name docuflow_app \
  -p 3000:3000 \
  -v /srv/files/DocuFlow:/srv/files/DocuFlow \
  -e NODE_ENV=production \
  -e PORT=3000 \
  -e STORAGE_DIR=/srv/files/DocuFlow \
  --restart unless-stopped \
  docuflow:latest
```

Сервис будет доступен по адресу: `http://localhost:3000` (или IP-адрес вашего сервера).

## ✨ Основные возможности

1. **Регистрация без Email**:
   * Для создания аккаунта требуется только логин (username) и пароль (минимум 4 символа). Электронная почта не запрашивается.
   * Опционально указывается ФИО для автоматической подписи документов.

2. **Защита доступа**:
   * Неавторизованные пользователи видят исключительно защищенную страницу авторизации/регистрации и не имеют доступа к функциям сайта до входа.

3. **Поддержка Word и Excel**:
   * **Word**: `.docx`, `.doc`, `.txt`
   * **Excel**: `.xlsx`, `.xlsm` (макросы), `.xls`
   * Автоматическая замена меток `{tag}`, формул, реквизитов и сумм прописью на русском языке.

4. **Загрузка архивов и целых папок (Drag & Drop)**:
   * Поддержка перетаскивания файлов прямо в окно браузера.
   * Можно загружать `.zip` архивы и папки — система автоматически фильтрует файлы и извлекает только поддерживаемые документы, предотвращая использование сервера в качестве файлопомойки.

5. **Архив готовых комплектов документов**:
   * Все сформированные комплекты автоматически группируются по **ФИО клиента и номеру договора**.
   * Скачивание отдельных документов или всего комплекта одним кликом в оригинале (`.docx`, `.xlsx`) и в `.pdf`.
   * Понятные имена файлов: `[ТипДокумента]_№[Номер]_[Фамилия_Инициалы]`.

6. **Ссылки для просмотра и скачивания готовых документов**:
   * Генерация ссылок для клиентов с настраиваемым сроком действия (1 час, 24 часа, 7 дней, бессрочно).
   * Режим **«Для 1 просмотра»**: ссылка автоматически сгорает после первого открытия получателем.

7. **Шеринг шаблонов и тегов по кодам**:
   * Возможность поделиться выбранными шаблонами и тегами с коллегами через короткий код (например, `DOC-7X9K2B`) или ссылку.

## 📁 Структура постоянного хранилища (`/srv/files/DocuFlow`)

```text
/srv/files/DocuFlow/
├── users.json             # База учетных записей пользователей (хэши pbkdf2)
├── sessions.json          # Активные сессии авторизации
├── shares.json            # Общедоступные шаблоны и теги по кодам
├── package_shares.json    # Временные и одноразовые ссылки на комплекты
├── templates/             # Персональные шаблоны пользователей ([userId].json)
└── tags/                  # Персональные теги пользователей ([userId].json)
```
